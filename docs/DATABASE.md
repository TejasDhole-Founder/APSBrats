# APSBrats Database Schema

PostgreSQL, managed by **Flyway** (`src/main/resources/db/migration`).
Companion doc: [`API.md`](./API.md).

---

## 1. Conventions

- **Primary keys**: `UUID`, generated by `uuid_generate_v4()` (needs `uuid-ossp` extension, created in V1). JPA entities use `@GeneratedValue`.
- **Naming**: tables/columns are `snake_case`; Java entity fields are `camelCase` mapped via Hibernate's default physical naming strategy (`lastReadAt` → `last_read_at`). Some fields use explicit `@Column(name=...)`.
- **Timestamps**: `created_at` / `updated_at` are `TIMESTAMP`. JVM and DB both run `Asia/Kolkata` (`SET TIME ZONE '+05:30'`).
- **Enums**: real PostgreSQL `ENUM` types. Entities map them with `@Enumerated(EnumType.STRING) @JdbcType(PostgreSQLEnumJdbcType.class)` + `columnDefinition`.
- **`ddl-auto: validate`** — Hibernate never alters schema; **every schema change needs a new migration**. New enums use a guarded `DO $$ ... EXCEPTION WHEN duplicate_object ... $$;` block; tables/indexes use `IF NOT EXISTS`.
- Flyway is baselined at version 4 on existing DBs (`baseline-on-migrate: true`).

### schools  (V2 + V3)
`id` UUID PK · `name` VARCHAR(150) NOT NULL · `city`, `state`, `cantonment` · `school_code` VARCHAR(20) UNIQUE · `address` TEXT · `principal_name` VARCHAR(150) · `phone` VARCHAR(50) · `email` VARCHAR(150) · `website` VARCHAR(200) · `is_active` BOOLEAN NOT NULL default TRUE · `created_at`. Index on `LOWER(name)`.

### user_school_history  (V4)
A user's enrolment at a school. `section` stores the grade+section **label** (e.g. `12A`).
| Column | Type | Notes |
|--------|------|-------|
| id | UUID PK | |
| user_id | UUID NOT NULL | FK→users ON DELETE CASCADE |
| school_id | UUID NOT NULL | FK→schools ON DELETE RESTRICT |
| class_from / class_to | SMALLINT NOT NULL | 1–12 |
| section | VARCHAR(5) NOT NULL | uppercase |
| batch_start / batch_end | SMALLINT NOT NULL | years |
| is_primary | BOOLEAN NOT NULL | default FALSE — drives `PersonDto` |
| created_at | TIMESTAMP NOT NULL | |

Checks: `class_from>=1 AND class_to<=12 AND class_to>=class_from`; `batch_end>=batch_start`; `section=UPPER(section)`.
Indexes: `(school_id, section, batch_start, batch_end)`, `(user_id)`.

### user_social_links  (V5)
`id` · `user_id` FK CASCADE · `platform` social_platform NOT NULL · `handle` VARCHAR(200) NOT NULL · `label` VARCHAR(50) (required for CUSTOM) · `is_visible` BOOLEAN NOT NULL default TRUE · `created_at`. **UNIQUE(user_id, platform)**.

### otp_codes  (V8)
One row per generated login code.
| Column | Type | Notes |
|--------|------|-------|
| id | UUID PK | |
| phone | VARCHAR(15) NOT NULL | indexed |
| code | VARCHAR(6) NOT NULL | 6 digits |
| expires_at | TIMESTAMP NOT NULL | now + 10 min |
| consumed | BOOLEAN NOT NULL | default FALSE |

Lookup: latest unconsumed code per phone. No FK to users (codes can precede signup).

### connections  (V9)
Symmetric batchmate links.
| Column | Type | Notes |
|--------|------|-------|
| id | UUID PK | |
| requester_id | UUID NOT NULL | FK→users CASCADE |
| addressee_id | UUID NOT NULL | FK→users CASCADE |
| status | connection_status NOT NULL | default PENDING |
| created_at | TIMESTAMP NOT NULL | |

Constraints: **UNIQUE(requester_id, addressee_id)**, CHECK `requester_id <> addressee_id`. Indexes on both FKs.
> Direction matters only for who requested; "accepted batchmates" query matches either side.

### feed_events  (V10)

`id` · `actor_id` UUID NOT NULL FK→users CASCADE · `type` feed_event_type NOT NULL · `title` VARCHAR(200) NOT NULL · `body` TEXT · `meta` VARCHAR(200) (e.g. `APS Patiala 12A`) · `created_at` TIMESTAMP NOT NULL. Index on `created_at`.

### community_members  (V11)
`id` · `community_id` FK CASCADE · `user_id` FK CASCADE · `last_read_at` TIMESTAMP (null = never read; drives `unreadCount`) · `joined_at` TIMESTAMP NOT NULL. **UNIQUE(community_id, user_id)**. Indexes on `user_id`, `community_id`.

### community_messages  (V11)
`id` · `community_id` FK CASCADE · `sender_id` FK→users CASCADE · `body` TEXT NOT NULL · `created_at` TIMESTAMP NOT NULL. Index `(community_id, created_at)`.

### conversations  (V12)
A 1-to-1 DM thread.
| Column | Type | Notes |
|--------|------|-------|
| id | UUID PK | |
| user_a_id | UUID NOT NULL | FK→users CASCADE |
| user_b_id | UUID NOT NULL | FK→users CASCADE |
| last_message_at | TIMESTAMP | for sorting the inbox |
| created_at | TIMESTAMP NOT NULL | |

Constraints: **UNIQUE(user_a_id, user_b_id)**, CHECK not-self. Service stores the pair in canonical (sorted) order so a thread is never duplicated. Indexes on both FKs.

### chat_messages  (V12)
`id` · `conversation_id` FK CASCADE · `sender_id` FK→users CASCADE · `body` TEXT NOT NULL · `read_at` TIMESTAMP (null = unread) · `created_at` TIMESTAMP NOT NULL. Index `(conversation_id, created_at)`.
> `unreadCount` for me = messages in the thread where `sender_id <> me AND read_at IS NULL`.

### notifications  (V13)
`id` · `user_id` FK→users CASCADE · `type` notification_type NOT NULL · `title` VARCHAR(200) NOT NULL · `body` TEXT · `is_read` BOOLEAN NOT NULL default FALSE · `created_at` TIMESTAMP NOT NULL. Index `(user_id, created_at)`. Created automatically on connection request/accept.

## 5. Relationships (text ER)

```
users 1───* user_school_history *───1 schools
users 1───* user_social_links
users 1───* connections (as requester and as addressee)
users 1───* feed_events (actor)
users *───* communities  via community_members
communities 1───* community_messages *───1 users (sender)
users *───* conversations (user_a / user_b)
conversations 1───* chat_messages *───1 users (sender)
users 1───* notifications
otp_codes — standalone, keyed by phone
```

## 7. Adding a new table — checklist
1. Write `V15__*.sql` with `IF NOT EXISTS` (and guarded `DO $$` block for any enum).
2. Create the `@Entity` with matching `@Column` names; enum fields use `@JdbcType(PostgreSQLEnumJdbcType.class)` + `columnDefinition`.
3. `JpaRepository`, service, `record` DTO, `@RestController` returning `ApiResponse`.
4. Get the current user with `SecurityUtils.currentUserId()`; never trust a userId from the URL for "me".
5. Restart — Flyway migrates, Hibernate `validate` confirms the mapping.
